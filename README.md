# 🛡️ Insurance Fraud Detection Using Machine Learning

## 📌 Project Overview

This project was completed as part of the **Advanced Certificate Programme in Applied Data Science** offered by **IIIT Bangalore**.

The objective was to develop a machine learning solution capable of identifying potentially fraudulent insurance claims using historical claim data. The project demonstrates a complete end-to-end machine learning workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, model development, hyperparameter tuning, and performance evaluation.

---

## 🎯 Business Problem

Insurance fraud results in billions of dollars in financial losses every year. Early identification of suspicious claims helps insurance companies reduce operational costs, minimise financial risk, and improve investigation efficiency.

This project aims to build predictive models that accurately distinguish fraudulent claims from legitimate ones while maintaining high recall to minimise missed fraud cases.

---

## 🎯 Project Objectives

- Perform comprehensive Exploratory Data Analysis (EDA)
- Clean and preprocess insurance claim data
- Handle class imbalance using Random Oversampling
- Engineer meaningful predictive features
- Train and compare multiple machine learning models
- Optimise model performance using hyperparameter tuning
- Evaluate models using industry-standard classification metrics

---

## 📂 Dataset

The project uses an insurance claims dataset containing customer, policy, and claim-related information.

**Dataset Characteristics**

- Approximately **1,000 records**
- Around **40 features**
- Binary classification problem:
  - Fraudulent Claim
  - Genuine Claim

## 📊 Model Performance

### Logistic Regression

- Accuracy: **93.96%**
- ROC-AUC Score: **0.979**

### Random Forest

- Recall: **97.44%**
- Precision: **81.72%**
- F1-Score: **88.89%**

The Random Forest model achieved the strongest fraud detection performance, providing an excellent balance between fraud recall and precision.
